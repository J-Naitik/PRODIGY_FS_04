# PRODIGY_FS_04

💬 Real-Time Chat Application

A real-time chat application built using the MERN stack (MongoDB, Express, React, Node.js) and WebSocket technology (Socket.IO) to enable instant messaging between users.

🚀 Features

✅ User authentication (Sign up / Login)
✅ Create and join chat rooms
✅ One-to-one and group chats
✅ Real-time text messaging using WebSocket
✅ Message timestamps

🧩 Optional Features

Chat history

Notifications

User online/offline presence indicators

Multimedia file sharing

🛠️ Tech Stack
Category	Technology
Frontend	React.js, Tailwind CSS
Backend	Node.js, Express.js
Database	MongoDB
Real-time	Socket.IO
Authentication	JWT (JSON Web Token)
⚙️ Installation and Setup

Follow these steps to run the project locally:

1️⃣ Clone the repository
git clone https://github.com/your-username/realtime-chat-app.git
cd realtime-chat-app

2️⃣ Install dependencies

Install dependencies for both backend and frontend:

Backend
cd backend
npm install

Frontend
cd ../frontend
npm install

▶️ Run the Application
Run Backend
cd backend
npm run dev

Run Frontend
cd frontend
npm run dev


The frontend will typically run on http://localhost:5173

and the backend on http://localhost:5000
.
